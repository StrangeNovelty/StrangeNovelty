01 · Getting started

Begin with a Work, then write one Scene.

Strange Novelty is a private creative operating system. A Work is the project: a novel, serial, short story, script, or comic. Volumes and Arcs are optional organizing layers. Chapters plan the reader's progression. Scenes contain prose.

The shortest useful path: create a Work, add a Chapter, create a Character, create the first Scene, and save a paragraph. Everything else can grow from that.

How saving works

Scene saves never overwrite history. Each successful save creates an immutable Revision. Planning snapshots preserve Chapter plans separately; Manuscripts select exact Scene Revisions for export.

02 · Writing

Structure supports the prose; it does not replace it.

The Story Workshop is one continuous path: Outline → Draft → Editor → Links → Story Engine → Scene Brief → Sliders → De-Slop → Continuity → Polish → Package → Publication. Move forward or backward as the Chapter needs.
Work
The whole creative project and its shared context.
Volume
An optional large division, useful for multi-book or serial structures.
Arc
An optional thematic or dramatic grouping that may cross structural divisions.
Chapter Intake
Purpose, goal, emotional direction, focus, and raw material.
Outline
The flexible structural plan in prose or list form.
Beat
One important turn: a discovery, reversal, decision, confrontation, hook, or transition.
Scene
The prose unit. Write, revise, connect context, and navigate in reader order here.
Scene Brief
A planning companion describing function, wants, conflict, stakes, setting, movement, and risks. It is not prose.
Pacing Profile
Your intended intensity across tension, dread, intimacy, energy, humor, action, and mystery. It is not a quality score.
Planning Snapshot
A restorable copy of Chapter planning, Beats, and pacing before major changes.

Series Map shows structure and reader order. Pacing Map compares intentional pacing signals. Writing statistics count positive additions without turning writing into gamification.

03 · Characters

Build a dossier around choices, voice, and change.

Each Character opens as a sectioned long-term workspace: Overview, Appearance, Personality, Backstory, Abilities, Relationships, Arc Notes, Progression, Evaluation, and Appearances. The stable header keeps Save state, Fill from Description, and AI Assist within reach without turning the dossier into one enormous page.

Identity and aliases distinguish the Character. Appearance records physical and sensory presence. Personality prose captures the overall pattern; optional Personality Sliders record useful tensions without making them diagnoses or fixed truth. Backstory preserves origins and formative events. Arc Notes keep planned movement and author predictions separate from established events.

Abilities describe individual powers or skills; Stages, Events, and Predictions track development. Work-specific Custom Mechanics may add a designation, Family source, shared abilities, configurable rules, and a costed Borrowed Ability Log without hard-coding one story system. Relationships record both Characters' perspectives. Family is visibly distinct from other Groups and personal Relationships. Evaluation is an author or review-first AI assessment; Appearances derives Chapter, Scene, POV, and Work backlinks.

Fill from Description proposes destination fields and marks existing values; only selected fields are applied. AI Assist attaches a Character-scoped Context Pack and routes focused suggestions into the normal review and Apply to Story workflow. Neither action changes canon silently.

04 · Worldbuilding

Choose the record that matches the scale of the idea.

Regions are broad territories or realms. Locations are places where story can happen. Groups and factions are organizations with members and goals. Codex entries define terms, systems, cultures, technologies, and custom mechanics. Items are important objects. Creatures are animals, species, monsters, or entities.

World Bible is the readable connected view. Structured World is where each record is maintained. They are two views of the same data, not competing sources.

05 · Continuity

Track what the story promises and who understands it.

A Plot Thread is an unresolved promise, mystery, question, conflict, or expected payoff. A Secret is a hidden truth. A Clue points toward a truth. A Reveal is the moment information is disclosed. Reader Knowledge records what the audience understands. Character Knowledge records what one Character knows, believes, suspects, or misunderstands.

Continuity asks: what has been promised, hidden, learned, reinforced, contradicted, or resolved? Timeline asks: when did an event occur?

06 · Timeline & Cross-Reference

Separate occurrence order from reader order.

Timeline Events use author-controlled sort positions and story-time labels, so fantasy calendars are optional. Precision can be exact, approximate, a range, relative, or unknown. Relations express before, after, simultaneous, overlaps, causes, enables, prevents, retells, flashbacks, prophecies, and alternatives.

Chronology says when something happened. Chapter and Scene order say when the reader encounters it. Cross-Reference answers supported questions about appearances and co-occurrence—such as Scenes containing multiple Characters or a Character at a Location—without exposing a query language.

07 · Decks

Move from prompt to interpretation to deliberate conversion.

The Deck Library stores native Card text and metadata. Review status says whether the transcription has been author-reviewed; extraction confidence only sets review priority. Pending and low-confidence Cards remain importable and reviewable without being automatically approved.

Create a free Draw or use an official Spread. Lock Cards you want to keep, redraw unlocked positions, attach selected story context, and write an author interpretation. AI interpretation remains separate. Conversions always show a preview and provenance; they never alter original Card content.

08 · AI Studio

Select context, choose a task, review everything.

Brainstorm is the unified Story Engine generator desk: Plot Seeds, Realm Builder, NPC Generator, Monster Generator, and Item Generator share selected Cards, story context, author focus, exclusions, persistent notes, and Apply to Story. A Context Pack is the reusable typed selection beneath that workflow. Story Chat keeps a conversation, but its responses are still suggestions.

Writing tasks route primarily to Aion, with GLM available as the retryable alternate. Outlining and analysis route to OpenAI. Brainstorming routes to Claude. The actual routing category and model are recorded on every request.

Editor, De-Slop, and Polish are deliberate reviewed passes rather than silent rewrites. Accepting an idea does not make it canon. Apply to Story or conversion is a separate explicit action, and Scene changes create immutable Revisions with stale-source protection.

09 · Research & Artwork

Keep evidence, interpretation, and story use distinct.

A Research Source is the book, article, URL, citation, or private file. A Research Note is your observation, excerpt, interpretation, question, or proposed story application. Extracted text is machine-derived and retains provenance; review excerpts before treating them as quotations.

Artwork stores private portraits, maps, diagrams, mood references, creature concepts, and item designs. Collections combine Sources, Notes, and Artwork into ordered research folders or mood boards. Only explicitly selected Library records enter AI context.

10 · Publishing

Compile exact Revisions before generating files.

A Manuscript Project selects and orders Chapters, Scenes, front matter, back matter, Artwork, and glossary material. Every included Scene resolves to an immutable Revision. Lock selections when you need a stable reading copy; stale warnings appear when newer prose exists.

Reading Preview shows the assembled manuscript before generation. Formatting Profiles control restrained output conventions. TXT, Markdown, HTML, DOCX, and PDF Exports preserve a source snapshot and remain privately downloadable. Publication Queue tracks planned or completed release state; exporting is not publishing.

13 · Common workflows

Eight paths through the creative system.

Start a new web serial

Create a web-serial Work → add Chapters in reader order → outline the first release → create Scenes → track episode hooks → add planned Publication Entries → compile a web-serial reading copy.

Plan a Chapter

Complete Intake → shape the Outline → add the decisive Beats → create or attach Scenes → create Scene Briefs → review pacing → capture a planning snapshot.

Write a Scene

Open the Chapter → Continue Writing → keep prose central → add only relevant Character and world context → save → confirm the new immutable Revision → move to the next Scene.

Develop a Character

Create the dossier → add goals, conflict, and voice → connect relationships and Groups → define Abilities and possible progression → link appearances, knowledge, Timeline Events, Research, and portraits.

Build a Location

Create its parent Region if useful → create the Location → describe atmosphere and current state → connect Characters, Groups, Research, Artwork, Scenes, and Timeline Events.

Track a Secret

Create the Secret → record objective truth → add Character and Reader Knowledge separately → add Clues → link the Reveal → connect chronology without confusing occurrence with disclosure.

Make a Deck Draw

Choose free or official Spread → select eligible Cards → lock and redraw deliberately → add story context → write an author interpretation → optionally request AI alternatives → review before conversion.

Ask AI for help

Create or choose a Context Pack → inspect Context Preview → choose a task or Story Chat → wait for the request → edit or reject the suggestion → explicitly apply or convert only what you want.

Compile a manuscript

Create a Manuscript Project → populate entries → choose exact Scene Revisions → inspect stale warnings → validate → read the Preview → confirm an Export → track publication separately.
