# Strange Novelty

Strange Novelty is a private, secure, web-based creative workspace for a solo author and artist.

It is intended to provide a coherent place for writing, worldbuilding, chronology, artwork, research, and related creative material. The product emphasizes authorial control, meaningful content states, navigable connections, deliberate AI assistance, privacy, portability, backup, and recovery.

AI may assist with creative and organizational work, but the author remains the final authority. AI-generated material does not become canon automatically.

## Repository Status

This repository is currently documentation-only. It contains product direction, principles, architectural planning, and decision records. It does not yet contain application code.

## Old Story Engine

The old Story Engine is reference-only. Its workflows, product ideas, and implementation lessons may inform Strange Novelty, but its architecture and behavior should not be copied without review.

Story material found in the old application may be incomplete or outdated. It must not be treated as current canon merely because it exists there.

## Private Data

Private story files belong under `private-data/`. This directory is ignored by Git and must never be committed.

Do not commit manuscripts, artwork, databases, exports, credentials, secrets, or other private creative material.
